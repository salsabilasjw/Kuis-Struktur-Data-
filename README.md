## Deskripsi Program

### Soal 1 --- Data Mahasiswa

Program untuk mengelola data mahasiswa. Di dalamnya digunakan Single
Linked List dan Dynamic Array. Program juga menggunakan Insertion Sort
untuk mengurutkan data, Linear Search untuk mencari NIM, dan Binary
Search untuk mencari data yang sudah terurut.

### Soal 2 --- Sistem Perpustakaan

Program simulasi perpustakaan yang menggunakan Queue untuk antrean,
Stack untuk riwayat, dan Binary Search Tree (BST) untuk menyimpan serta
mencari data buku. BST juga ditampilkan dengan traversal Preorder,
Inorder, dan Postorder.

### Soal 3 --- Graph Kampus

Program menggambarkan graph kampus menggunakan Adjacency Matrix.
Penelusuran graph dilakukan dengan BFS dan DFS, sedangkan Dijkstra
digunakan untuk mencari jalur terpendek.

### Soal 4 --- Hash Table

Program menyimpan data mahasiswa menggunakan Hash Table dengan metode
Double Hashing. Fitur yang tersedia yaitu menambah, mencari, menghapus,
dan menampilkan data.
